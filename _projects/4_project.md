In less than 36 hours, my team and I tried our best to solve a major problem in the United States: not enough pets are being adopted. We wanted to make adoption feel easy and engaging, so we built a Tinder-style interface that lets users swipe left on pets they are not interested in and swipe right on pets they want to save for later.

The following technologies were used in the making of this project:
- React (Vite)
- JavaScript
- HTML
- Node.js
- Auth0
- Petfinder API
