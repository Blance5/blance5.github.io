With a team of 3 others I had never met before, we built a full-stack application that helps users model the damage a potential hurricane could cause. We wanted to make hurricane risk easier to understand, so the app lets users draw a storm path, select their location, and compare likely outcomes through maps and generated statistics.

This project won the Knight Hacks 2023 Best Use of Google Cloud category.

The following technologies were used in the making of this project:
- Google Maps API
- JavaScript/HTML/CSS
- Google Maps Visualization, Places, and Drawing Libraries
- Node.js
- Google Maps Heatmap
- ChatGPT integration to query hurricane statistics
